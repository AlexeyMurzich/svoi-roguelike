# Мимикратор — концепт v1

Новый элитный враг: красивая парящая фея с узнаваемыми чертами по трём фотографиям пользователя. Вокруг летают плюшевый мишка, маленькая мидия и полицейская мигалка.

Первый вариант для согласования. Создан встроенным image_gen. Файл mimicrator-v1.png; запрос prompt-v1.txt. В бой пока не подключён; боевые способности не заданы. Фотографии в проект не копировались.

## v2 — опасная палитра

По запросу пользователя: тёмно-фиолетовое платье, багровая магия, холодные тени, опасные крылья. Лицо, поза и три спутника сохранены. mimicrator-v2.png создан встроенным image_gen, запрос prompt-v2.txt. Варианты сохранены отдельно.

## v3 — сходство и единая отрисовка

Уточнены лицо и причёска по фотографиям, свет и живописная интеграция головы. Опасная палитра и окружение сохранены. mimicrator-v3.png, встроенный image_gen, запрос prompt-v3.txt. Для согласования.

## v4 — скрытая угроза

Лицо v3 согласовано, сохранено. Алое свечение приглушено; дымчато-синие/сливовые цвета, серебристо-лиловая магия, редкие винные акценты. Мишка без светящихся красных глаз. mimicrator-v4.png создан встроенным image_gen, запрос prompt-v4.txt. Для согласования.

## Демонстрация v0.14

v4 согласован. Раздельные рабочие слои: assets/enemies/mimicrator-body.png и mimicrator-props.png; запросы layer-prompts.txt. Native WinForms/GDI+ демонстрация запускается Launch-preview-mimicrator.cmd, в главном меню также есть кнопка. Бой/способности элитки не реализованы.

## Боевые формы v0.15

Мимикратор подключён к элитным комнатам. Fairy → Beacon → Bear → Mussel, затем повтор трёх предметов. Для закрывания раковины встроенным image_gen создан mimicrator-shell.png, запрос shell-animation-prompt.txt. Превращения, атаки, луч, щит и птички оглушения анимируются в игре. Быстрый запуск Launch-test-mimicrator.cmd.
