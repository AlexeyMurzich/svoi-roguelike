# Работа с проектом

- Сначала прочитать HANDOFF.md. Продолжать текущую игру, не создавать заново.
- Продукт — нативное Windows EXE. Не переделывать в сайт, Electron или браузерную игру.
- Стек: C# 5, .NET Framework 4.8, WinForms, System.Drawing. Сборка build.ps1 старым csc.exe, без SDK, NuGet и новых языковых возможностей.
- Не менять утверждённые лица, графику, баланс или механику без задачи пользователя. Новые карты и большие игровые системы согласуются отдельно.
- Изображения принадлежат ImageAssets; не создавать дубли исходных bitmap на каждого врага/кадр. Временные снимки DeathVisuals освобождать.
- Правила боя в CombatState/HeroState, визуальные эффекты отдельно. Урон/оплата применяются ровно один раз в момент попадания.
- Сохранять паузу, остановку при потере фокуса, независимость от частоты кадров и очистку при выходе из боя.
- C# UTF-8 BOM/CRLF, CMD без BOM. Старый csc требует обратных слешей в аргументах путей исходников.
- Собирать с предупреждениями как ошибками. После существенных изменений запускать подходящие проверки; для релиза полный run-tests.ps1 и визуальная проверка затронутых экранов.
- Пользователь общается по-русски, предпочитает краткие понятные итоги и рабочий билд. Не спрашивать повторных подтверждений для уже порученной работы.
- Не коммитить EXE, ZIP, временные файлы, личные фотографии и секреты. Не менять видимость репозитория без указания владельца.
