## Сцены и уровни

В главном меню сразу звучит тема выбранного героя. Касса, карта и все обычные бои, включая Бабая и Тоху,
продолжают тему героя. Бой и показ Мимикратора используют отдельную композицию; выход возвращает тему героя.
Музыкальные исходники и PCM не менялись. Повторный SyncMusic/новый ход/карта не перезапускают тот же трек.

- Музыка: gain 0.28; во время карт, воя и наезда Тохи — 0.095 (примерно −9.4 dB относительно фона).
- Приглушение: экспоненциальная огибающая, постоянная времени 35 мс. Возврат: 320 мс.
- Атака карты: 0.76; защита: 0.65. В WAV-мастерах дополнительно сохранён запас по пикам.
- Новое действие за 90 мс убирает предыдущий карточный хвост. Максимум две карточные voice; старый хвост не обрезает новый эффект.
- Одновременные автокарты Илли получают один акцент на партию: атакующий при наличии атаки, иначе защитный.
  Подготовка пропускается, т.к. действие модели уже завершено; край сглаживается за 1.5 мс. Механики/оплата/число карт не менялись.
- Моторы Тохи: 0.60; вой: 0.55. SoundPlayer больше не используется — все каналы независимы.

Windows сводит независимые waveOut voices, приложение управляет уровнями и приоритетом хвостов.
Новых таймеров/потоков для эффектов нет: существующий MotionDriver обновляет огибающие и освобождает завершённые voice.
Он продолжает короткую работу после визуальной анимации до окончания аудиохвоста. Прежний фоновый загрузчик музыки сохранён.
Ошибка устройства не меняет карточное действие и не закрывает игру.

## Синхронизация и жизненный цикл

Полные эффекты запускаются один раз в StartCombatAnimation вместе со стартом принятого действия.
Подготовка и полёт уже в файлах: попадание — 0.5 / 1.2 ≈ 417 мс, блок — 0.2 / 1.2 ≈ 167 мс.
Урон/оплата остаются в прежнем единственном callback. Изменение HitTime/Speed требует пересогласования звука.
Пауза, колода, реликвии, консоль и потеря фокуса приостанавливают все каналы и их огибающие; возврат продолжает позицию.
Выход из боя убирает эффекты, Dispose освобождает native buffers. Скрытые тестовые окна не открывают устройство.

## Пересборка

`./build.ps1` использует готовые ресурсы — без Python, NuGet, SDK и внешних аудиокодеков.
Повторно упаковать WAV-мастера в SVOIPCM1 + gzip без изменения PCM-сэмплов:

```powershell
python Tools/prepare-card-audio.py
```

Пересоздать оригинальные эффекты с фиксированными seed (нужны numpy, Pillow, soundfile):

```powershell
python Tools/audio/generate_cards.py work/card-sfx-v2
python Tools/prepare-card-audio.py --import-v2 work/card-sfx-v2
```

Песни: `python Tools/prepare-music.py assets/music/source assets/music`.
Эффекты синтезированы с нуля, без сэмплов Slay the Spire или других игр. Исторический v1 для пересборки не требуется.
Если v1 есть рядом с рабочим выводом, генератор дополнительно сравнит энергию удара.

Протокол текущего билда: [AUDIO-v0.29.md](AUDIO-v0.29.md). Технические проверки не заменяют субъективную оценку звучания.
