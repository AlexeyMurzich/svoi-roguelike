# Свои люди — v0.13.1

Карточный roguelike для друзей: четыре героя, Беларусь и локальные шутки.
Нативное приложение для Windows на C# 5 / .NET Framework 4.8 / WinForms.
Это развиваемый прототип, а не законченная игра.

## Что уже работает

- Выбор Пупсолета, Илли, Рунцо или Шутена и одной из трёх персональных стартовых реликвий на кассе Евроопта.
- Процедурная карта Смолевичей: Социал → Старый центр → Поместье Фомченко. По пять уровней; в каждом районе минимум элитка, костёр и магазин, во всём акте минимум десять вопросов.
- Стартовая колода: три атаки по 6 и три защиты по 5; добор, сброс, перемешивание, энергия или золото.
- Бои с крысой, двумя собаками или парой разных ежей. Отдельные HP, выбор цели перед каждой атакующей картой, анимации атак и смерти.
- Полный экран, изменение размеров окна, пауза, плавное перемещение карты и подсказки реликвий.

В v0.13.1 оба ежа находятся в одном бою. Колючий стреляет иглами на 10 и отвечает шипами на 2 за каждую атаку. Безумный кусает на 5; если пробивает блок, накладывает до конца боя бешенство: +2 силы и −2 ловкости, без накопления. Цель можно свободно менять между картами одного хода.

## Сборка и запуск

Нужна Windows с .NET Framework 4.8. Отдельный SDK и NuGet не требуются.

```powershell
.\build.ps1
.\run-tests.ps1
.\package.ps1
```

Версия задаётся в GameVersion.cs. Сборка создаёт Svoi-v0.13.1.exe, упаковка — outputs/Svoi-v0.13.1-Windows.zip. В EXE встроены 33 изображения; папка assets нужна для пересборки, не для запуска.

Быстрые запуски из исходников сами используют текущую версию:
- Launch-test-battle.cmd — крыса;
- Launch-test-dogs.cmd — две собаки;
- Launch-test-hedgehogs.cmd — два ежа;
- Launch-test-hedgehog.cmd и Launch-test-rabid-hedgehog.cmd — совместимые запуски той же пары ежей.

В бою кликните по модели, имени или HP живого врага, затем по карте. Золотой указатель отмечает цель. После завершения анимации её можно сменить для следующей карты. Esc — пауза; F11 / Alt+Enter — окно/полный экран; D — колода; R — реликвии.
