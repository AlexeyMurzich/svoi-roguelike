# Свои люди

Закрытый проект: карточный roguelike для друзей, Windows EXE, C# 5 / WinForms / .NET Framework 4.8. Текущая версия **v0.12**.

Это рабочая основа игры: выбор четырёх героев, стартовая реликвия на кассе Евроопта, процедурный первый акт и первые бои.

Для продолжения в новом чате сначала прочитать [HANDOFF.md](HANDOFF.md), затем [AGENTS.md](AGENTS.md). Инструкции игрока — [README.txt](README.txt).

## Сборка и запуск

На Windows установленный .NET Framework 4.8 содержит нужный компилятор, отдельный .NET SDK не требуется.

```powershell
./build.ps1
./Launch-test-dogs.cmd
```

`Svoi-v0.12.exe` запускает обычный выбор персонажа. `Launch-test-battle.cmd` открывает бой с крысой, `Launch-test-dogs.cmd` — бой с двумя собаками за Шутена.

31 используемое изображение из `assets` встраивается в EXE; старые атласы Шутена сохранены только как референсы. Результат сборки самодостаточен, внешняя папка графики для запуска не нужна.

```powershell
./run-tests.ps1
```

Полная проверка v0.12: 41 набор без ошибок, 1 129 143 утверждения; отдельно проверен EXE без внешней папки assets. Подробности — [VALIDATION.md](VALIDATION.md), протокол — [test-results.txt](test-results.txt).

## Последние изменения

- Исправлены пропорции ног Шутена и привязка четырёх боевых поз; убрано полупрозрачное двоение фигуры.
- Смерть всех текущих сущностей фиксирует позу при попадании и корректно работает при паузе/resize.
- Очередь атак сохраняет время между кадрами, урон/оплата однократные.
- Разделены управление боем, отрисовка и геометрия; добавлены ограниченные кэши карт и маршрута.
- Внеэкранный замер боя 1280×840: медиана 125.87 → 35.14 мс; память исходных bitmap 100.87 → 72.53 МиБ. Это не обещание живого FPS.

Отчёт — [REFACTOR-v0.12.md](REFACTOR-v0.12.md). После сборки `./package.ps1` создаёт автономный ZIP в outputs. Версия задаётся в GameVersion.cs. Для адресной проверки: `./run-tests.ps1 -Filter 'Refactor:'`.

Исходные фотографии друзей не включены: в репозитории находятся утверждённые игровые изображения. Не публиковать репозиторий и изображения без решения владельца.
