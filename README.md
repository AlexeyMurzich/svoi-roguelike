# Свои люди

Закрытый проект: карточный roguelike для друзей, Windows EXE, C# 5 / WinForms / .NET Framework 4.8. Текущая версия **v0.11**.

Это рабочая основа игры: выбор четырёх героев, стартовая реликвия на кассе Евроопта, процедурный первый акт и первые бои.

Для продолжения в новом чате сначала прочитать [HANDOFF.md](HANDOFF.md), затем [AGENTS.md](AGENTS.md). Инструкции игрока — [README.txt](README.txt).

## Сборка и запуск

На Windows установленный .NET Framework 4.8 содержит нужный компилятор, отдельный .NET SDK не требуется.

```powershell
./build.ps1
./Launch-test-dogs.cmd
```

`Svoi-v0.11.exe` запускает обычный выбор персонажа. `Launch-test-battle.cmd` открывает бой с крысой, `Launch-test-dogs.cmd` — бой с двумя собаками за Шутена.

Все 32 изображения из `assets` встраиваются в EXE. Результат сборки самодостаточен, внешняя папка графики для запуска не нужна.

```powershell
./run-tests.ps1
```

Полная проверка v0.11: 38 наборов без ошибок, затем адресная проверка изменения размера окна во время смерти. Подробности — [VALIDATION.md](VALIDATION.md), протокол — [test-results.txt](test-results.txt).

## Последние изменения

- Две собаки с отдельными HP и выбором цели; цикл укус/укус/вой со сдвигом.
- Анимация смерти крысы, собак и всех четырёх героев.
- Шутен защищается большой кредиткой, оставаясь на велотренажёре.

Исходные фотографии друзей не включены: в репозитории находятся утверждённые игровые изображения. Не публиковать репозиторий и изображения без решения владельца.
