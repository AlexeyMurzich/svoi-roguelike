# v0.30 — единый программный микшер

Причина скачков в v0.29: `waveOutSetVolume` использовался для отдельных эффектов, но Windows связывает эти вызовы
с общей аудиосессией приложения. Громкость карточного хвоста могла менять весь фон. Эти вызовы полностью удалены.
Справка: [Microsoft — legacy audio/session volume](https://github.com/MicrosoftDocs/win32/blob/docs/desktop-src/CoreAudio/audio-events-for-legacy-audio-applications.md).

## Реализация

- `AudioLevels`: единственное место уровней. Музыка 0.07; атаки/защиты/моторы 0.18; вой 0.16.
- `AudioLevels.PrepareMusic`: одна статическая калибровка всей песни по RMS/пику при загрузке. Файлы не меняются.
- `SoftwareAudioMixer`: независимые позиции/паузы/gain; суммирование в PCM, 22.05/48kHz и mono поддерживаются.
- `WaveOutMixerOutput`: один native device, один audio worker, три переиспользуемых буфера; объём очереди около 35 мс.
- `LoopingMusicVoice`: совместимый фасад логического канала, без изменения громкости Windows.
- Песни героев — только после выбора в главном меню. Касса/карта/обычные бои/Тоха/Бабай их не используют.
- Мимикратор сохраняет отдельную тему в бою. Фон не реагирует уровнем на карты, врагов или конец эффекта.
- Ограничение до двух карточных каналов и затухание старого хвоста сохранены, но влияют только на эффект.

Обычная динамика самой песни сохранена. Речь о постоянном уровне музыкального канала, независимом от игровых действий.

## Подтверждение

Целевые программные проверки микшера, уровней, PCM, загрузки, паузы, native output и сцен прошли.
Полный прогон: **95 наборов, 0 ошибок, 1 279 521 утверждение**; test-results.txt. Production и тесты собраны с предупреждениями как ошибками.

`Tools/RenderAudioMix.cs` пропустил реальные музыку и четыре эффекта через production-микшер.
Для каждого отсчёта проверено `общий микс − эффекты = исходный музыкальный канал` с погрешностью не больше одного PCM-отсчёта
(округление PCM16). Значит ни старт карты, ни изменение её уровня не меняют вклад музыки.
Пик тестового микса: 4801/32767, примерно −16.7 dBFS; перегруза нет.
Предпрослушивание: локальный `work/mixer-review-v030.wav`, 9 с. Исходник инструмента сохранён для повторения.

Установленный EXE без assets прошёл **17 live-проверок**, включая общий единственный output, уменьшенный уровень карты,
постоянную музыку, паузу/продолжение, сцены и освобождение native device/worker при закрытии.
Протокол: `AUDIO-live-v0.30.txt`. Субъективное прослушивание ассистентом не заявляется.
