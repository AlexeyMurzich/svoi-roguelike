СВОИ ЛЮДИ — v0.16
Windows / .NET Framework 4.8

Запуск: Svoi-v0.16.exe. Все игровые изображения встроены.
Быстрые проверки:
Launch-test-battle.cmd — крыса.
Launch-test-dogs.cmd — две собаки.
Launch-test-hedgehogs.cmd — колючий и безумный ежи вместе.
Launch-test-hedgehog.cmd / Launch-test-rabid-hedgehog.cmd также открывают пару.

МИМИКРАТОР — БОЙ И ПОКАЗ АНИМАЦИИ
Launch-test-mimicrator.cmd — сразу бой за Шутена с кольцом.
Launch-preview-mimicrator.cmd или кнопка в главном меню.
Фея парит; предметы движутся вокруг неё с магическим следом.
Пробел — пауза, Esc — вернуться. Это отдельный показ модели.

Выберите героя и стартовую реликвию на кассе Евроопта.
Карта Смолевичей: Социал → Старый центр → Поместье Фомченко.

УПРАВЛЕНИЕ
Клик по доступной комнате — перейти; колесо/перетаскивание — карта.
В бою клик по модели, имени или HP врага выбирает цель.
Золотой указатель показывает выбранного врага. Затем нажмите карту.
В одном ходе можно бить разные цели разными картами.
Уже начатая атака сохраняет свою цель; следующую выбирайте после анимации.
Esc — пауза, главное меню и выход.
F11 или Alt+Enter — полный экран / окно.
D — колода, R — реликвии. Описание реликвии — по наведению.

БОЙ
Колода: 3 Удара по 6 и 3 Защиты по 5. Добор 3, энергия 3.
Сыгранные карты уходят в сброс; при пустой колоде сброс перемешивается.
Илля добирает ещё 2 и автоматически играет 2 случайные карты.
Шутен платит золотом и теряет 1 золото в начале хода.
Для первой проверки Шутена удобно выбрать кольцо с 300 золотом.
Долг разрешает только реликвия «Мобильный телефон», долг снимает HP.

Крыса кусает на 5.
Две собаки действуют по очереди: два укуса по 5, затем вой.
Циклы сдвинуты; вой снижает урон атак на 25% на следующий ход.
Колючий ёж стреляет иглами на 10. Каждая атакующая карта по нему
вызывает ответ шипов на 2, даже добивающая. Блок поглощает шипы.
Безумный ёж кусает на 5. Потеря HP от укуса накладывает бешенство
до конца боя: +2 силы, −2 ловкости. Повторно не складывается.
У каждого ежа 30 HP. Победа — после гибели обоих.

Мимикратор: 60 HP, первый раунд фея (5 урона), затем по кругу:
мигалка (6 урона + оглушение), мишка (14 урона), мидия (12 блока).
Оглушение: следующий ход можно сыграть только одну карту,
включая автоматические карты Илли. Добор обычный.
Блок поглощает урон мигалки, но не оглушение.
Блок мидии действует до её следующего действия.

Это прототип. Обычные и элитные бои работают; остальные комнаты, награды,
сохранения забега, следующие акты и полный спутник Рунцо ещё не готовы.

Сохранены анимации покоя v0.15: дыхание/покачивание, головы собак, слюна.
