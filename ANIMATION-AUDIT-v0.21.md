# Аудит анимаций v0.21

База: main 85e51810bccfd5a2b26c855cdfc97b4a0e1da56c (v0.20). Нативный Windows EXE сохранён.

Исправления: точка крепления головы собак перенесена внутрь непрозрачного корпуса для всех трёх поз, геометрия масштабируется целиком. Переходы собак и крысы используют один непрозрачный кадр, без двойных полупрозрачных голов. Слюна больше не пропадает во время атаки героя из-за устаревшего индекса врага. Остаточная защитная поза затухает и вне активной атаки.

Рефакторинг: эффекты попаданий выделены в CombatImpactEffects.cs. ActorArtCache использует ключ-структуру и LRU-вытеснение отдельных изображений вместо полной очистки; лимиты 24 MiB / 48 кадров сохранены. Крупные формы Мимикратора используют тот же кэш. Таймер использует 16 мс во время действий и 33 мс в покое; время анимаций остаётся независимым от частоты кадров.

Проверки: сборка с предупреждениями как ошибками; две целевые проверки Audit, 115 утверждений, ошибок нет. Они покрывают соединение шеи при разных масштабах/позах, непрозрачность, лимит кэша и затухание защиты. Полный прогон остановлен по просьбе пользователя сократить проверки и расход токенов: его успешное завершение НЕ заявляется. Замеры производительности были сделаны при параллельно работающих тестах, поэтому численный прирост FPS не заявляется. Изменения оптимизации подтверждаются ограничением кэша и снижением частоты фоновой перерисовки.

Второй PR будет содержать атаки/защиту остальных героев. Этот PR не менять баланс, не объединять автоматически.

Дополнительно: проверка неподвижности лап собак — 115 утверждений, ошибок нет; итоговый контактный лист dog-animation-contact-sheet.png просмотрен. Всего три целевых набора, 230 утверждений.
