# Кассир Евроопта

`cashier.png` — согласованный пользователем второй вариант персонажа, PNG RGBA 1145×1374 с прозрачным фоном. Скопирован побайтно из outputs/cashier-concept-v1/cashier-vibecoder-v2.png. SHA256: b34f4aa7e3c7c9803344ff2878ce336e9affb2ca65a3934565406d6f25f6c4a4.

Встроенный image_gen, правка выражения лица по двум фотографиям пользователя. Личные фотографии в репозиторий не добавлены. Точный финальный промпт — cashier-prompt.md.

Мимика и улыбка остаются частью утверждённого рисунка. Движение дыхания и временные смещения полос рисует CheckoutCashier.cs по отдельному сценическому времени CashierAnimation. Единственный владелец исходного bitmap — ImageAssets, размерные копии — ограниченный actorArtCache.
