# Фоматрешка — утверждённая графика

Все PNG — самостоятельные изображения с альфа-каналом, встроенные в EXE. Исходные фотографии не входят в каталог или репозиторий.

| Файл | Использование |
|---|---|
| 01-idle-hair.png | Старший до первого призыва, волосы на лице |
| 02-summon.png | Смахивание волос, открытое лицо и призыв |
| 03-gorilla.png | Исправленная и утверждённая поза питья Gorilla v8 |
| 04-empress.png | Выстрел из AK-47 «Императрица» |
| minion-01-glasses.png | Девушка №1, имя в бою «Фанатка» |
| minion-03-ponytail.png | Девушка №3, имя в бою «Фанатка» |
| minion-04-redhead.png | Девушка №4, имя в бою «Фанатка» |

Основные позы и девушки утверждены пользователем; Gorilla одобрена после отдельной правки. Промпты: POSES-PROMPTS.md, FAN-PROMPTS.md и PROMPTS.md. Исторические формулировки «для проверки» в промптах описывают момент генерации, итоговое одобрение зафиксировано здесь. manifest.json содержит контрольные суммы поставляемых изображений.

Новые исходники во время боя не создаются: семь изображений лениво загружает общий ImageAssets, а уменьшенные варианты хранит ограниченный actorArtCache. Свечение бодрости, дыхание, движение при призыве, выпады, отдача и побег рисуются игровым кодом FomatreshkaBattle.cs. Утверждённые лица в PNG при этом не меняются. Свечение бодрости активно только после Gorilla и до завершения следующего выстрела.
