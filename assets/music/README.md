# Музыка игры

Файлы предоставлены пользователем из папки «Песни для игры». Исходные OGG
скопированы без изменений в source/. manifest.json содержит их SHA256,
частоту, каналы и полное число кадров.

- Тема Пупсолета.ogg → pupsolet → меню, касса, карта и бои Пупсолета.
- Тема Илли.ogg → illya → меню, касса, карта и бои Илли.
- Тема Рунцо.ogg → runtso → меню, касса, карта и бои Рунцо.
- Тема Шутен.ogg → shuten → меню, касса, карта и бои Шутена.
- Мимикратор.ogg → mimicrator → бой и показ Мимикратора.

Нет обрезки, ресэмплинга, добавленной тишины или изменений громкости в файлах.
OGG декодированы в PCM16, 44100Hz stereo с исходным числом кадров. gzip
только сжимает PCM без потерь. Пять *.pcm.gz встраиваются в EXE; исходные OGG
и Python в установленной игре не нужны. Обычная сборка остаётся C#5/csc без
NuGet, SDK и внешних аудиокодеков.

Для замены/повторной подготовки нужен Python с пакетом soundfile:
python Tools/prepare-music.py assets/music/source assets/music

Подготовка использует SoundFile/libsndfile:
https://python-soundfile.readthedocs.io/en/latest/
Runtime использует Windows waveOut, независимые каналы музыки и эффектов.
Зацикливание одним нативным буфером WHDR_BEGINLOOP|WHDR_ENDLOOP, dwLoops=uint.MaxValue
(практически непрерывно, без таймера перезапуска и вставленной паузы).
https://learn.microsoft.com/en-us/windows/win32/api/mmeapi/ns-mmeapi-wavehdr

Музыка загружается фоновым потоком; предыдущая тема останавливается до новой,
отменённые загрузки молчат. Пауза/меню/консоль/потеря фокуса сохраняют позицию.
С v0.29 музыкальный gain — 0.28; во время карт/воя/моторов плавно снижается до 0.095 и возвращается.
Сэмплы песен не изменены. Политика каналов и каталог: [AUDIO.md](../../AUDIO.md).
