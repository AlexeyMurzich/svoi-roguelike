# Цифровой сбой кассира

Источник — переданный пользователем двухсекундный MP3 ElevenLabs, сохранён без изменений в source/elevenlabs-connection-lost.mp3. Все две секунды использованы целиком. Подготовка: Tools/prepare-cashier-audio.py. Нужны numpy/soundfile.

Частота 44100 Hz, stereo PCM16. По 5 мс края против щелчков, один постоянный gain до RMS 0.18; без динамического ducking, сжатия времени или повторного синтеза. Точные числа и хеши в manifest.json. WAV/OGG для прослушивания — outputs/cashier-integration. В EXE встраивается только glitch.pcm.gz.

CashierSound использует один однократный канал существующего микшера, gain AudioLevels.Cashier = 0.12. Звук запускается на начале редкого двухсекундного события, не перекрывает сам себя, сохраняет позицию в паузе, останавливается при выходе из кассы и освобождается по завершении.
