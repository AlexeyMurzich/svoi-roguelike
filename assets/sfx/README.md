# Звуки атак Тохи

Два синтезированных звука мотора из согласованных пользователем предпрослушиваний, 27 октября 2026. Это стилизованные эффекты, не записи конкретных моделей автомобиля.

- toha-light.pcm.gz: светлая форма, 1.42 с.
- toha-dark.pcm.gz: тёмная форма, 1.55 с.

48 kHz, stereo, signed PCM16. Контейнер тот же SVOIPCM1 + gzip, что у музыки; данные образцов сохранены побайтно из WAV предпрослушивания. Длины и SHA256 в manifest.json. Никакой повторной генерации, обрезки или добавленной тишины при интеграции.

Встраиваются build.ps1 под именами sfx.toha-light.pcm.gz и sfx.toha-dark.pcm.gz. TohaAttackSound лениво декодирует каждый клип один раз; native waveOut проигрывает его без повтора независимо от музыки. Без дополнительных потоков и таймеров. Исходный preview WAV для запуска не требуется.
