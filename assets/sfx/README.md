# Эффекты

Общий каталог звука, сцены и уровни: [AUDIO.md](../../AUDIO.md).

- `cards/source/*.wav`: восемь WAV-мастеров v2, имена `<hero>-attack` / `<hero>-guard`. `runtso` соответствует Рунцо.
- `cards/previews/*.ogg`: компактные файлы для отдельного прослушивания.
- `cards/runtime/*.pcm.gz`: игровые ресурсы SVOIPCM1 + неизменённый PCM16.
- `cards/manifest.json`: мастер → превью → ресурс, SHA256 файлов и PCM, длина и момент действия.
- `toha-light.pcm.gz`, `toha-dark.pcm.gz`: прежние утверждённые наезды Тохи, не изменены и не перемещены.
- `manifest.json`: прежние контрольные суммы наездов Тохи.
- Вой собак синтезируется в `HowlSound.cs`; внешний файл не нужен.

Генератор: `Tools/audio/generate_cards.py`. Упаковка: `Tools/prepare-card-audio.py`.
EXE/ZIP и временные варианты звуков сюда не складывать.

Моторы Тохи — два синтезированных эффекта из согласованных предпрослушиваний от 27 октября 2026,
светлый 1.42 с и тёмный 1.55 с, 48 kHz stereo PCM16. Это стилизация, не запись конкретной модели автомобиля.
Сэмплы сохранены побайтно, без повторной генерации, обрезки и добавленной тишины.
Ресурсы `sfx.toha-light.pcm.gz` и `sfx.toha-dark.pcm.gz` лениво декодируются TohaAttackSound и играют однократно.
